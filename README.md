# The Story Current — Next.js

A Next.js 14 App Router news and editorial CMS prototype. Content and admin sessions are currently persisted in browser storage; see `src/docs/DEPLOYMENT.md` for the production data-layer plan.

## Getting Started

1. Run `npm install`
2. Run `npm run dev`
3. Open `http://localhost:3000`

Create a production build with `npm run build`, then run it with `npm start`.
